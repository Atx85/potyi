Pötyi

A desktop editor for macOS, Windows and Linux, built for writing code with less on screen.

It started as a personal project: a place to edit files without a busy interface. It has two editing panes, a command bar, and a terminal for running commands.

Free and open source, written in Rust and SDL3. Still in development.

Working in Pötyi

Open a file or folder

Drop a file onto the window, or use potyi . from a shell to open the current folder.

Choose your shortcuts

Use conventional shortcuts, or switch to the supported Vim-style or Emacs-style bindings.

Add language tools as needed

Editing works on its own. Optional language servers add completion, navigation and refactoring. LSP setup guide.

File-backed storage

Pötyi reads file content as needed instead of copying the whole document into memory when it opens. Edit history still grows as you work, and optional language tools use their own resources.

About the name

Pötyi is a playful nod to the Hungarian word pötyögni—to tap away on a keyboard. A fitting name for a little text editor. Potyi is the spelling without accents used in commands and downloads.

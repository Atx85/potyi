Pötyi is a focused text editor built in Rust and SDL3. It keeps memory and CPU use low while putting search, navigation, split editing, and a practical command terminal close at hand.

What it does

The useful parts of a serious editor, without the sprawl.

01

One command bar

Search, replace, navigate, open files, adjust settings, save, and quit from one discoverable place. Press Ctrl + P or type : on an empty line.

:goto 120:4
02

Split editing

Open two documents side by side. Each pane keeps its own cursor, selection, scroll position, and undo history.

03

Practical Vim mode

Optional Normal, Insert, and Visual modes cover everyday motions, operators, search, paste, undo, redo, and repeat.

04

Command terminal

Run ordinary, non-interactive shell commands without leaving the editor. Printed file locations are clickable.

05

Search that stays live

Preview results as you type, search forward or backward, use regular expressions, and replace one match or all of them.

06

File-backed by design

A piece table keeps large files editable without making a complete in-memory copy. Pötyi sleeps while idle to keep resource use predictable.

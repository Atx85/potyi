A native editor for the files in front of you

Pötyi text editor.
Light on your system.

Pötyi (also written Potyi) is a free, open-source text and code editor for macOS, Windows, and Linux, built in Rust and SDL3. It keeps memory and CPU use low while putting search, navigation, split editing, and a practical command terminal close at hand.

Say it like “PUR-chee” — leave out the r sound
Closer Hungarian pronunciation

Start as if saying “purr,” but stop before the r. Keep that vowel short and round your lips. Finish with a soft “chee,” with the stress on the first part. Exact IPA: /ˈpøci/

What it does

Code editing, with the tools close at hand.

01

One command bar

Search, replace, navigate, open files, adjust settings, save, and quit from one discoverable place. Press Ctrl + P or type : on an empty line.

:goto 12 --rel
02

Split editing

Open two documents side by side. Each pane keeps its own cursor, selection, scroll position, and undo history.

03

Practical Vim mode

Optional Normal, Insert, and Visual modes cover everyday motions, operators, search, paste, undo, redo, and repeat.

04

Command terminal

Run ordinary, non-interactive shell commands without leaving the editor. Printed file locations are clickable.

05

Search that stays live

Preview results as you type, search forward or backward, use regular expressions, and replace one match or all of them.

06

File-backed by design

A piece table keeps large files editable without making a complete in-memory copy. Pötyi sleeps while idle to keep resource use predictable.

low memory · low CPU
07

Language servers and rename

Inspect types and documentation, jump to definitions, and preview function or variable renames across files. Language servers are optional and start when requested. Set up LSP.

08

Edit repeated text together

Use Cmd+D or Ctrl+D in conventional mode to select matching occurrences. Move, select, type, and paste at multiple cursors, with grouped undo.

About the Pötyi code editor

Are Pötyi and Potyi the same editor?

Yes. Pötyi is the Hungarian name; Potyi is its spelling without accents and the name used in the GitHub repository and downloads.

Which platforms does it support?

Pötyi builds for macOS on Apple Silicon and Intel, Windows, and Linux. Choose a platform download above, or build the Rust source yourself.

Do I need to install a language server?

Only for features such as hover, go-to-definition, and symbol rename. Editing, search, split panes, and the command terminal work without one.

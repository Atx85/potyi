FROM HERE TO YOUR EDITOR
Three steps. Your colors.
No plugin installation needed.
  1. 1
    Extract your settings
    In Pötyi, run :extract-config to create the config/syntax/ folder.
  2. 2
    Add the downloaded file
    Place it in that folder, beneath Pötyi’s working directory. When changing an existing language, replace its matching definition so each extension has one custom definition.
  3. 3
    Reopen your document
    Pötyi selects the definition by its file extension. Open the file again to see your changes.

    
A note about previews and long files
The preview uses the same Rust regex matcher, overlap handling, and UTF-8 offsets as Pötyi. Each line is limited to 16 KiB and 1,024 candidate matches. The designer accepts up to 32 rules and shows the first 200 lines of a sample up to 16 KiB. Large or complex patterns may reach its compilation limit.
Highlighting is line-based: multiline strings, comments, and embedded languages are approximate. Colors may also look different with another font or display. Changes stay in this tab until you download them; reloading starts fresh.
